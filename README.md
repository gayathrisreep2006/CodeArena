# CodeArena – Coding Practice and Live Contest Platform

## 📌 Project Overview
CodeArena is a web-based coding platform developed using Python and Django. It provides an interactive environment for users to practise programming, submit solutions, participate in live coding contests, and track their performance.

## ✨ Key Features
- User authentication and role-based access.
- Programming problem management.
- Python code submission with automatic evaluation.
- Sample and hidden test case verification.
- Live contests with unique room codes.
- Leaderboards, submission history, and performance dashboard.
- CSV export for contest results.

## 👥 User Roles

| Role | Responsibilities |
|---|---|
| **Player** | Solve problems, submit code, join contests, and view results. |
| **Host** | Create and manage problems, test cases, and contest rooms. |
| **Admin** | Manage users, roles, problems, and overall platform activities. |

## 🚀 Getting Started

```bash
git clone https://github.com/gayathrisreep2006/CodeArena.git
cd CodeArena
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open `http://127.0.0.1:8000/` in your browser.
